# Penetration Testing Workflow - Metasploitable2

## Objective

To understand the penetration testing lifecycle through reconnaissance, scanning, vulnerability identification, exploitation attempts, and reporting.

## Tools Used

- Kali Linux
- Nmap
- Metasploit Framework
- Metasploitable2
- UTM

## Methodology

1. Reconnaissance
2. Scanning & Enumeration
3. Vulnerability Identification
4. Exploitation Attempt
5. Reporting

## Findings

Multiple services were exposed on the target system including FTP, SSH, HTTP, SMB, MySQL and PostgreSQL.

## Recommendations

- Apply security patches
- Disable unnecessary services
- Implement firewall controls
- Perform regular security assessments
